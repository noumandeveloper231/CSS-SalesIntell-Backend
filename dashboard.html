📋 How to get your Anthropic API key:
1. Go to console.anthropic.com and sign in (or create a free account)
2. Click API Keys in the left sidebar
3. Click + Create Key → give it a name (e.g. "CSS SalesIntell") → copy the key
4. Paste it in the field above and click Test API Key to verify
5. Click Save All Changes to write it to your .env file
